# Daily Kakeibo Web Viewer

端末内にデータを保存する家計簿PWAです。iPhoneアプリのバックアップJSONを読み込むと、月別の収支、カテゴリー別支出、記録、月次レポートを表示できます。収入・支出やレシート写真を追加すると、このブラウザの端末内ストレージに自動保存します。

## 使い方

1. iPhoneアプリで「設定 → データ管理 → バックアップファイルを保存」を選びます。
2. iPhoneではSafariでこのページを開き、共有メニューから「ホーム画面に追加」します。
3. ホーム画面のアイコンから起動し、「バックアップを読み込む」からiPhoneアプリのJSONを選びます。Safariのタブとホーム画面アプリは保存領域が別になることがあるため、初回読込はホーム画面アプリ内で行ってください。
4. 記録やレシート写真は入力時に自動保存され、次回起動時に読み込まれます。記録をタップすると詳細を確認でき、「この記録を編集」から日付・種類・カテゴリー・金額・メモを変更できます。編集内容は端末内に自動保存されます。レシート写真をタップすると拡大表示できます。円グラフを含む月別の集計も端末内で表示します。
5. 必要なときにバックアップJSONを書き出せます。旧iPhoneアプリへ戻す場合は「設定 → データ管理 → バックアップを復元」から読み込みます。

記録とレシート画像はIndexedDBに保存し、サイトのサーバーへは送信しません。保存領域はブラウザ・ホーム画面アプリごと、端末ごとに別管理です。Safariのサイトデータ削除や端末のストレージ管理により消える場合があるため、バックアップJSONを定期的に書き出してください。

**注意:** iPhoneアプリでバックアップを復元すると、iPhone内の記録・カテゴリー・設定などが読み込んだバックアップの内容に置き換わります。復元前にiPhone側の最新バックアップを保存してください。

## GitHub Pagesで公開する

この `web/` ディレクトリの中身を、Web版専用のGitHubリポジトリのルートに置いてください。`.github/workflows/pages.yml` がGitHub Pagesへ自動デプロイします。

1. GitHubで公開リポジトリを作成します。
2. `web/` の中身をリポジトリ直下へ登録して `main` にpushします。
3. リポジトリの **Settings → Pages → Build and deployment** で **GitHub Actions** を選びます。
4. **Actions** タブでデプロイ完了を確認し、表示されたPages URLを開きます。

バックアップJSON、家計データ、レシート画像をリポジトリへ追加しないでください。公開対象はWeb画面のファイルだけにします。
